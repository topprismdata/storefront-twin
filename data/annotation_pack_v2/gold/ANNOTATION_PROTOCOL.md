# 左邻右舍门头识别 金标准标注协议 v1.0

**用途**: P0-A 人工双盲金标准。产出 (a) 注册表标签的人工复核结论 (b) 人-机一致性基线(Kappa) (c) 仲裁后的真值参照。
**铁律**: 标注员**不得**接触 gold_key.json、注册表、任何模型输出(E8-G 分数/VLM 判决/聚类结论)。违反即报废该批标注。
**版权**: 全部图片 rights=pending_review,仅限本项目内部评估,禁止外传/商用。

## 1. 任务定义

对每张图给**四态裁决**(记录表填缩写):

| 缩写 | 裁决 | 含义 |
|---|---|---|
| M | MATCH | 真左邻右舍便利店的真实经营门店 |
| N | NON_MATCH | 明确的其他竞品便利店品牌 |
| U | UNKNOWN | 看不清/无法判断(招牌不可读、遮挡、过远、糊) |
| O | OUT_OF_SCOPE | 非门头照片(室内/设计图/logo素材/地图/同名非便利店等) |

## 2. 品牌身份证据(判 M 的必要条件 a)

满足其一即可,两者俱全更稳:
1. **标准字**: 可读"左邻·右舍"或"左邻右舍"(含常见排版变体)。
2. **⊙圆环标志**: 红底白字圆环符号 + 红 #e60012 / 蓝 #005dac 红蓝 VI。

已知门店样式变体(都是 M,不因风格陌生而拒):
- **CS-01 编号标准型**: 红底白字 + 门头编号
- **CS-02 书法字体型**: 书法体"左邻右舍"(非标准黑体)
- **CS-03 红蓝常规型**: 红/蓝色带常规排布
- **CS-04 立体发光字型**: LED 立体发光字(夜间/侧视角常见)
- **CS-05 PLUS升级型**: "左邻右舍 PLUS"字样
- **CS-06 超市型**: 左邻右舍+超市/生活超市组合业态

## 3. 真实经营场景证据(判 M 的必要条件 b)

照片必须是**真实拍摄**的门店门头/入口,可见至少一项: 玻璃门、货架商品、入口结构、街景透视、自然光影。

**品牌文字 + 真实场景,缺一不可。**

## 4. 边界规则(判例库,按真实冲突案例沉淀)

| 情形 | 裁决 | 依据判例 |
|---|---|---|
| 立体发光字/斜侧视角/远景门店,文字可辨+场景真实 | **M** | img_0483 曾被 VLM 误拒——不得因字体立体/透视误判 |
| 平面 logo 设计稿/纯色背景艺术字/书法插画/海报 | **O** | img_0038 曾被 VLM 误收——品牌文字不足以判 M |
| 渲染效果图/占位模板("便利店名称""XXX便利店"占位字) | **U** | 无法确认真伪又不属明确他牌 |
| 缩略图/低清不可辨 | **U**,禁止猜字 | img_0488 判例——512px 不可读就 U |
| 竞品: 美宜佳/全家/7-11/芙蓉兴盛/邻几/罗森等 | **N** | 有可读竞品招牌即 N |
| 同名非便利店: 餐馆/超市/烟酒店/食品商行/社区标牌/小区门 | **O** | "左邻右舍"餐馆=同名异业 |
| 室内货架/地图截图/软件界面 | **O** | 非门头 |
| 招牌被遮挡只露局部,无法确认品牌 | **U** | — |
| 同一门店多张相似照 | 独立判,不因"眼熟"而放水 | 盲标纪律 |

**犹豫时**: 先问"品牌身份证据"是否达标,再问"真实场景"是否达标;任一不达标即降级(U 或 O)。U 与 O 之别: O=我能说出它**是什么**(室内图/设计图/某竞品);U=我说不出它是什么。

## 5. 流程

1. 两名标注员**独立**标注 gold_sheet_00..19.jpg(每张 20 格,A#### 编号)。可放大原图: `images/A####.jpg`。
2. 记录: `gold_manifest.csv` 的 annotator1 / annotator2 列填 M/N/U/O。允许分多次完成(约 30-60 秒/张,总计 3.5-7 小时/人)。
3. 标完跑 `python3 synthetic/kappa_tool.py data/annotation_pack_v2/gold/gold_manifest.csv`:
   - kappa ≥ 0.75 → 自动合并共识,输出 `registry_label_errors.json`(注册表疑误清单)
   - kappa < 0.75 → 逐分歧仲裁(`arbitration.csv`,第三人裁决+全分辨率复核),仲裁完成后重算
4. 仲裁终值 + key 对账 → 注册表修正(如有) → 该 400 张即金标准真值。

## 6. 质量底线

- 每人先试标 10 张熟悉协议(样张另发,不入正式 400)。
- 单人速率异常(<10s/张)的批次作废重标。
- 对 U 的使用不做配额,但 U 占比 >25% 时仲裁员应复核该批次的视力/屏幕条件。
