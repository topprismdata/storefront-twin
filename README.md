# 门店门头数字孪生与视觉识别：连锁品牌门头资产平台方法论

**面向任意连锁加盟品牌的门头资产管理方法论：合成数据训练 + 视觉证据层 + 权利安全取数。解决加盟品牌共同的三件事——门头资产不可见、商标搭便车、取数即侵权。**

> 试点实证：连锁便利店品牌"左邻·右舍"（本项目首个完整跑通的品牌）。方法与代码品牌无关，迁移新品牌只需替换三样输入：VI 参考图、品牌词库、SI 手册切片。

## 连锁加盟品牌的共性痛点

1. **门头资产不可见**：门店分散在县镇街巷，多数品牌没有完整门店台账；门头 VI 合规只能人工巡查，成本高、覆盖低。
2. **商标搭便车**：品牌名辨识度高就有人蹭——本试点实测发现同名喜铺、同名烟酒店、绿底杂牌"超市"等异业门店，维权缺乏线索清单。
3. **取数即侵权**：门头照片散落在地图 POI 相册与街景中，直接抓取训练存在权利风险；授权走通前一条真实照片都不能进训练集。

## 方法论：四个可复用组件

```
① 合成训练底座    SI手册→Blender参数化3D门店孪生→多角度合成图→视觉基线(LOSO冻结协议)
② VLM证据层      四态裁决(MATCH/NON_MATCH/UNKNOWN/OUT_OF_SCOPE)+UNKNOWN回退基线,只作证据不作训练标签
③ 真实数据管线    公开地图POI批量采集→接触表品牌核验→分层抽检质检→双盲标注→权利门(G0/G1)
④ 治理闸门        预注册验收协议、逐张权利审查、阈值泄漏控制、measured/reported分离
```

## 为什么成立：行业先例

| 案例 | 证明了什么 | 对本方法的意义 |
|---|---|---|
| **NVIDIA Kinetic Vision**（2021） | 合成数据训练的零售视觉模型可达部署精度，基础设施成本约降 16%，Fleet Command 边缘落地 | 合成训练→真实部署在零售场景成立 |
| **7-Eleven 台湾货架合规**（Sci. Reports 2025） | 1.9 万张货架图，商品检测 mAP 99.41%，Web 自查闭环 | "远程合规稽查"有直接商业价值 |
| **Neurolabs CPGDet-129**（2026） | 纯合成数据（转台×SKU）训练，11 万张推理集约 99.35%，零真实标注 | 商品级可零真实标注；本方法升级到**门头级**（户外/小目标/遮挡/同名陷阱，无公开基准） |
| **Domain Randomization**（Tobin 2017）及 2025 混合训练研究 | 多样性>真实性；纯合成有域差上限 | 试点 v2 扩量实验实测证实上限（见下） |

## 试点实证结果（左邻右舍，均为实测，探索性）

- **门头识别管线**：合成基线（330 评估）F1 0.862 → VLM 四态盲测层叠加后 **F1 0.951**（29TP/2FP/1FN），对街景/POI 图批量输出真门店/同名搭便车/竞品/不确定四态裁决。
- **台账重建**：公开地图数据 1178 POI → 核验 **~841 家真实门头候选**（抽检 precision 94.4% [87.5, 97.6]），远超品牌方自有的 30 张照片——等于从公开数据重建了缺失的门店台账。
- **商标维权线索**：85 家同名异业定位到 POI，可直接交法务。
- **边界实测**：合成扩量 +300 难负例无增益（域差上限）；探针融合 +AP/−F1 混合证据；A 类候选 96.6% 集中浙江（地域泛化未验证）。详见 `synthetic/GPT_TWIN_REPORT.md` §十、`data/gen_verify/VERIFICATION_REPORT.md`。

**三条产品线共用同一底座**：门头稽查（VI 合规远程审计）/ 台账重建（门店网络可视化）/ 商标维权（侵权线索清单）。

## 诚实边界

- **权利门未过**：试点真实照片全部 `rights=pending_review`，本仓库**不含任何真实图像、品牌 SI 扫描件与模型权重**，仅文档、代码、元数据。
- 全部数字为**探索性**；金标准双盲标注未开始；独立泛化验收前不宣称泛化准确率。
- 方法论目前只在单一品牌上端到端验证——多品牌泛化是明确的下一步（见 `dl/` 迁移清单）。
