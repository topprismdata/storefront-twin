## 关键结果（均为实测，探索性）

- **E8-G 冻结基线**（合成训练，330 评估）：P 0.800 / R 0.933 / F1 0.862，AuPR 0.925。
- **E10 VLM 盲测层**：VLM 四态裁决 + UNKNOWN 回退；Mode B F1 0.951（29TP/2FP/1FN）。
- **探针消融终局**：探针在融合内 ΔAP +0.041 但 ΔF1 −0.023（混合证据）；无探针 CLIP+DINO F1 0.885 为全系统最高；v2 合成扩量（+300 难负例）无增益，路线关闭。详见 `synthetic/GPT_TWIN_REPORT.md` §十。
- **真实门店候选核验**：1178 店/2542 图 → A 真门头 891（75.6%）→ 10% 从严抽检 precision 94.4% [87.5, 97.6] → 估计 ~841 家（780–869，候选级）。详见 `data/gen_verify/VERIFICATION_REPORT.md`。
- **结构局限**：A 类 96.6% 集中浙江；泛化宣称须附带此局限。
