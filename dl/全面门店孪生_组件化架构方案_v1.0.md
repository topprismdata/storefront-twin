# 全面门店数字孪生：组件化架构方案 v1.0

日期：2026-11-12 ｜ 状态：草案
战略定位（用户明确）：**门头识别只是第一步，最终目标是全面门店数字孪生。**
行业依据：快消零售门店孪生已是成熟产业（Kinetic Vision+NVIDIA、Neurolabs ZIA、Clobotics 2万店、7-Eleven台湾7000+店），核心范式＝合成数据训练→门店孪生仿真验证→再训练。

## 1. 分层组件架构（可扩展，不写死门头）
```
门店孪生框架 StoreTwin
├── 组件层 Components（每个独立可渲染 + 自带真值）
│   ├── C1 门头/招牌 Signage      ← 当前已实现（m1_3d_twin_v2.py）
│   ├── C2 全立面 Facade          ← 建筑/入口/雨棚/邻栋（Geometry Nodes 插件加速）
│   ├── C3 室内 Interior          ← 货架/商品/收银/布局（快消主战场）
│   ├── C4 陈列 Planogram         ← SKU 排面/合规比对（对标 7-Eleven/Clobotics）
│   └── C5 环境 Context           ← 街景/光照/天气/遮挡/传感器
├── 装配层 Assembler（组件→完整门店，参数化布局）
├── 随机化层 Randomizer（域随机化：相机/光照/材质/ clutter，Tobin 2017）
├── 真值层 GroundTruth（统一 schema：bbox/polygon/分割/深度/SKU标签）
└── 渲染层 Renderer（BlenderProc / Omniverse Replicator，自动标注+多GPU）
```

## 2. 组件接口契约（每个组件必须实现）
```python
class StoreComponent:
    def build(self, rng, params) -> dict:      # 生成几何+材质，返回组件句柄
    def ground_truth(self, cam) -> dict:       # 投影真值（polygon/bbox/label）
    def randomize(self, rng): ...              # 域随机化旋钮
    metadata: {component_id, version, source_policy, asset_status}
```
- 门头组件已有雏形：`build_sign()` 返回 comps + geom，`sign_polygon` 真值。
- 室内组件需新增：货架排面真值（每个 SKU 的 bbox + 类别 + 排面位置）。

## 4. 工具选型（实测对比）
| 工具 | 优势 | 劣势 | 适配阶段 |
|---|---|---|---|
| **BlenderProc**（GPL-3） | 已用 Blender，零迁移；脚本化域随机化+自动真值；开源 | 单 GPU 为主 | **近期首选**（门头→室内） |
| **Omniverse Replicator** | 物理级渲染；OpenUSD；自动 depth/分割/bbox；多 GPU；工业生态 | 需 Omniverse 生态，重 | 中期（全店物理孪生+规模化） |
| **Unity Perception** | Neurolabs 验证（CPGDet-129）；实时 | 转 Unity 成本 | 备选（货架 SKU） |
| **Geometry Nodes 插件**（Nodee/Buildify） | 参数化立面/楼层/窗，加速 C2 | 仅建筑，需定制门头 | C2 全立面组件 |

**决策**：近期用 BlenderProc 升级现有 Blender 管线（保留 m1_3d_twin_v2 组件逻辑，套 BlenderProc 的渲染+标注+随机化框架）；中期评估 Omniverse 做物理级全店孪生。

## 6. 域随机化原则（文献 Tobin 2017 + 混合训练）
- **变化度 > 保真度**：相机 yaw±75°/pitch±35°/dist 3–22m、光照全向、材质/背景/clutter/传感器噪声全随机。
- **混合训练甜区**：合成 60–80% + 真实 20–40%（需权利门）。纯合成→"两个世界"陷阱（当前探针 AuPR 0.324 即此症状）。
- **真实锚定**：新采集 2542 候选/1178 店提供真实分布锚点（权利门后）。

## 7. 治理（硬约束，贯穿所有组件）
- self_created / synthetic_train_only；程序化纹理，**绝不以真实照片为背景/贴图**。
- 真实数据 rights=pending_review，G0/G1 未过不训练不部署。
- VLM 裁决=推理证据，非训练标签。组件 asset_status=candidate_unverified。

## 8. 分阶段执行
- **阶段 1（进行中）**：门头 v2 宽域孪生 + 探针对比实证（验证域随机化有效性）。
- **阶段 2**：BlenderProc 集成 + C2 全立面组件 + 室内 C3 货架组件（修当前室内暗盒短板）。
- **阶段 3**：C4 陈列合规 + 统一真值 schema + 多组件装配。
- **阶段 4**：Omniverse 物理级全店孪生评估 + 真实数据混合训练（权利门后）。
