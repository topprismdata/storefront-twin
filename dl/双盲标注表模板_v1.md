# 双盲标注表模板（独立泛化集金标准）

依据：设计文档 §4.4 + 预注册协议 prereg_independent_test_v1.json。
原则：标注员**不知模型预测、不知对方标签、不知样本来源批次**；VLM 裁决不展示给标注员。

## 标注员 A / B 独立填写（每人一份，互不可见）

| 字段 | 说明 | 示例 |
|---|---|---|
| image_id | 匿名编号（不露来源） | gen_0001 |
| is_real_photo | 是否真实拍摄照片（非渲染/素材） | yes/no |
| is_storefront | 是否门店门头/入口（非室内/地图/海报） | yes/no |
| brand_text | 招牌可读文字（逐字，读不清填" unreadable"，禁猜） | 左邻·右舍 |
| has_circle_vi | 有无⊙圆环标志 | yes/no/unclear |
| has_redblue_vi | 有无红#e60012/蓝#005dac标准配色 | yes/no/unclear |
| brand_verdict | 品牌裁决 | own_brand / competitor / same_name_other / other / unreadable |
| competitor_name | 若竞品，品牌名 | 邻几 |
| scene_evidence | 真实经营场景证据（玻璃门/货架/街景透视/自然光） | 玻璃门+货架+街景 |
| style_cluster | 版型簇（CS-01..06/unknown） | CS-04 |
| confidence | 自评置信 | high/med/low |
| note | 备注（遮挡/倾斜/模糊等） | 立体发光字,斜侧 |

## 裁决规则（第三方）
- A/B 一致 → 直接采纳为金标准。
- A/B 不一致 → 第三方独立复核全分辨率 → 裁决；记录分歧原因。
- **own_brand 金标准须同时满足**：真实照片 + 门店门头 + 可读"左邻·右舍"标准字或⊙圆环+红蓝VI。仅文字无场景/仅VI无文字 → 降级复核。
- 成语/社区文化墙/教育素材含"左邻右舍"但非便利店 → same_name_other（负例），不得判 own_brand。

## 汇总字段（裁决后）
gold_label（positive/negative）、neg_type（competitor/same_name_unrelated/render_stock/indoor/logo/map/uncertain）、store_id、photo_family、geo_bucket、rights_status、adjudication_note。

## 隔离校验（采集后自动）
- store_id 与现有 322 组零交集（脚本校验）。
- sha256 + dHash(Hamming≤12) 跨源去重。
- 标注完成前冻结模型不得见 gold_label。
