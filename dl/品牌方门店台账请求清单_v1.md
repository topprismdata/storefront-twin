# 致驰骋控股集团：门店台账与形象确认请求清单

用途：左邻右舍门头视觉识别研究——独立新门店泛化集采集（探索性，非商业部署）。
现状：公开搜索 POI 索引近枯竭，已核验正例仅 30 张 / 7 家独立门店，统计效力有限。需品牌方协助突破采集瓶颈。

## 一、门店台账（P0，最高优先）
请提供加盟门店清单（可脱敏），每条含：
| 字段 | 必需 | 说明 |
|---|---|---|
| 门店编号 | ✓ | 唯一 store_id |
| 门店名称 | ✓ | 如"左邻右舍便利超市(XX店)" |
| 省/市/区 | ✓ | 地域覆盖（现集中浙江+福建，需≥4省） |
| 详细地址 | ✓ | 用于地图 POI 定位 |
| 地图 POI ID | 可选 | 高德/百度 place ID，可直接取相册 |
| 门头版型 | 可选 | 标准/简约/都市/PLUS（见下） |
| 开业/升级时间 | 可选 | 版型演变 |

**重点请求**：书法字体型门头、超市型门头的门店（当前各仅 1 张样本，是识别瓶颈）。

## 二、形象标准确认（E2/E3 门禁）
1. 官方 SI 三版（简约 jyb / 标准 bzb / 都市 dsb）的门头规范确认：红#e60012 / 蓝#005dac / ⊙圆环 / "左邻·右舍"标准字。
2. **PLUS 与英文副标**：官方标准门头无 PLUS/英文，但真实门店存在 PLUS 变体。请确认 PLUS 对应的加盟/升级版本规则（视觉版本 L1 ≠ 加盟合同 L4）。
3. 书法字体型、超市型是否为官方认可版型？对应哪类门店？

## 三、图像授权（权利门 G0/G1）
1. 品牌方自有门店照片的**研究使用授权**（哪些可用、是否可训练、署名要求）。
2. 地图 POI 相册图（高德/百度用户上传）的权利归属与使用边界。
3. 公开网络图（ Bing/素材站）默认仅可链接、未授权不训练——请确认品牌方能否提供已授权替代图。

## 四、标注协助（金标准）
1. 品牌方能否派员参与**双盲标注**（识别真门店 vs 同名异业 vs 竞品）？
2. 同名无关实体（住宅小区/园区/商贸城/餐饮）的官方排除清单。

## 五、研究边界承诺（我方）
- 探索性研究，G0/G1 未过前不部署、不对外宣称准确率。
- VLM 裁决仅作推理证据，不自动作训练标签。
- 合成数据 self_created；不使用未授权真实图训练。
- 所有结果标注 measured vs 推断，接受品牌方复核。

## 联系与交付
- 台账格式：CSV/Excel 均可（字段见上）。
- 交付后我方流程：去重 → 地图定位采集 → 全分辨率核验 → 双盲标注 → 冻结模型盲测 → 泛化报告。
