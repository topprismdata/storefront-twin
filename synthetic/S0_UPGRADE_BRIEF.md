# S0 目录外拒识升级 — GPT 评审简报

## 背景
连锁品牌门头识别 demo(本地单图 <0.5s,全离线):CLIP top-5 gallery 候选 + DINO 裁剪相似度 + 42 个 one-vs-rest 逻辑回归探针 + PP-OCR 文字/别名匹配。决策序:目录别名命中(text_cand/text_all)→ 视觉回退(visual_fallback)。此前的拒识规则:可读文字≥4 汉字但无别名命中→unknown;探针 margin<0.02→unknown。其余视觉回退瞎猜。

## 本轮变更(S0)
1. 高德新采 256 张**目录外**门头(瑞幸/库迪/蜜雪冰城/茶百道/钱大妈/生鲜传奇/易捷/昆仑好客/36524/可的,咖啡/茶饮/生鲜/加油站品类;sha256+dhash 对 14,757 张历史账本去重)。
2. 新增 FOREIGN 目录外知名品牌别名表(30 个品牌,含英文 LUCKIN/MIXUE/KFC 等):OCR 命中→直答"非目录·品牌名"。目录别名**先于** FOREIGN 检查(目录店挂竞品广告不吃亏)。
3. 短别名(≤2 汉字或 ≤3 拉丁字符)必须**独立整行**命中,防货架/海报子串误触发。
4. 视觉回退路径:OCR 有 ≥4 连续拉丁字母(真英文招牌)且无目录别名命中→unknown。

## 自审 3 轮发现并已修复
1. TODAY 既是目录品牌又被我放进 FOREIGN——删除(目录别名先命中,FOREIGN 分支永远不会触发,且语义矛盾)。
2. 康师傅/统一是**货架饮料品牌**不是门头品牌,放进 FOREIGN 会让目录店读出饮料柜文字被答"非目录"——删除。
3. "非目录·易捷" vs 真值串"易捷便利店"——计数口径假错;修正后 foreign 报错牌从 17 → 真实 1。
4. 目录内唯一误触发"地区一鸣"含"一鸣"子串——独立行门控修复,1→0。

## 已知局限(不打算在 S0 解决)
1. **88/256 错进目录全是 OCR 无字/乱码的纯视觉路径**,探针高置信瞎猜(瑞幸→7-11 margin 0.97)。文献称为"细粒度开集"难题(未知便利店品牌 vs 已知便利店品牌)。
2. 多品牌同框(易捷+茶百道相邻)取最长匹配会报错牌。
3. 拉丁规则对目录品牌误拒 3.6%——用粗糙启发式付的税。
4. 演示口径 vs E25 基准口径:demo 决策层比 E25 评分协议严格(拒识换诚实),79.6% 与 95% 不直接可比。

## 升级路线(评审重点)
- **S1**:现有 CLIP 塔 + 文本提示做零样本 OOD 打分(MCM/CLIPN"学会说不"/AdaNeg 负向提示,NeurIPS'25 思路),用 v18 的 256 张标注校准阈值,替换拍的规则。
- **S2**:把 v18+local 当**显式负类**重训探针(outlier exposure),让"都不是"成为可学习输出。
- **S3**:unknown 样本(约 10-34%)路由到本地小 VLM(oMLX 跑 Qwen2.5-VL)做四态裁决;联网时用 GPT。E10 盲测已实证 VLM 层 F1 0.951,只是现在要本地化。
