# 左邻·右舍门头识别项目：独立第三方技术评审

**评审立场：按照一个有潜力进入真实商业环境的计算机视觉研究项目，而不是一个内部 AI Demo 来评价。**

我先给出总体判断：

这个项目的水平明显高于一般的企业内部 AI 原型。它真正有价值的地方，不是 CLIP、DINOv2、SigLIP 或 VLM 的组合，而是已经形成了一套相对完整的研究闭环：数据构建、难负例识别、冻结基线、模型对照、跨集检验、失败归因、证据裁决和治理门禁。

但我也要明确指出：

**项目目前最重要的研究结论，并不是 VLM 能够显著提升门头识别精度，而是：在当前数据条件下，VLM 的开发集优势无法稳定迁移到独立数据集；而且真正限制系统可靠性的，仍然是数据域覆盖、真值质量和复杂门店边界。**

这是一个值得继续研究的项目，但距离能够证明其具备稳定商业识别能力，还有明显距离。

# 二、研究价值：6.2/10

<badge color="success">值得继续研究</badge>

### 1. 真正有价值的研究贡献

我认为有三个。

**第一：四态身份裁决比传统二分类更符合实际业务问题。**

你们不是简单判断：

- 是左邻右舍；
- 不是左邻右舍。

而是引入：

- MATCH
- NON_MATCH
- UNKNOWN
- OUT_OF_SCOPE

这个区分有实际意义。

例如：

| 场景 | 二分类的风险 | 四态机制的价值 |
|---|---|---|
| 真实门店但招牌被遮挡 | 可能误拒 | UNKNOWN |
| 品牌 Logo 设计图 | 可能误收 | OUT_OF_SCOPE |
| 同名异业餐馆 | 可能误收 | NON_MATCH |
| 真实品牌门头 | 正确识别 | MATCH |

尤其是将真实经营场景作为品牌身份验证的必要证据，而不是仅凭品牌文字判断。

这使问题从 Logo 分类转向了带有场景约束的视觉身份验证。

不过要强调：四态分类本身不是全新的学术贡献。其价值主要在于针对具体业务场景建立了明确、可审计的决策语义。

**第二：分层架构的设计方向合理。**

视觉基线负责召回，VLM 负责证据裁决。

这是合理的职责划分：

- 视觉模型提供相对稳定的候选判断。
- VLM 对场景、品牌身份和异常情况进行语义分析。
- UNKNOWN 通过不同回退模式处理。

但当前结果尚未证明这套架构一定优于简单的视觉模型。

GEN 集上：

| 方法 | F1 |
|---|---:|
| E8-G 基线 | 0.891 |
| VLM alone | 0.885 |
| Mode A | 0.917 |
| Mode B | 0.909 |

A 模式的 F1 领先基线 0.026，B 模式领先 0.018，但全部配对差的置信区间跨零。

所以正确的研究结论应该是：

> VLM 证据裁决具有改善独立集表现的初步迹象，但尚未获得统计上充分的优势证据。

而不是 VLM 已经证明能够提升识别精度。

<Cite refs={[]}/>

**第三：失败实验形成了有价值的知识资产。**

我尤其认可 E7b。

DINOv2 微调后：

- 验证集 F1 达到 0.93。
- 冻结阈值下测试 F1 下降至 0.504。
- 59 个误报中有 36 个来自 render_stock。
- 域内最优也只有 0.727。

这个结果说明模型可能学习了数据采集和素材分布中的伪相关特征，而不是稳定的品牌身份特征。

OCR 硬门禁失败、AnyLoc 结果撤回、E7 金标签训练失败，也都属于有效的研究发现。

这些失败并没有被藏起来，这一点很重要。

### 2. 为什么研究价值不是 8 分？

因为目前三个关键问题没有解决：

1. 四态机制是否能在不同品牌、不同城市和不同采集条件下成立？
2. VLM 相对视觉基线的增益是否具有可重复性？
3. 当前方法能否在明确的真实业务先验下，控制误识别风险？

目前的证据主要支持一个品牌、一个主要地理场景和同期采集数据。

**我的判断：这是一个有方法论价值的应用研究，但还没有形成足够强的、可推广的学术方法贡献。**

# 三、工程实现水平：7.4/10

<badge color="success">较高水平的研究型工程原型</badge>

这是我给分最高的维度。

### 1. 与业界、学界同类项目比较

下面是我的校准估计，不是来自统一行业统计数据库的实测排名。

| 比较对象 | 本项目估计位置 | 评价 |
|---|---:|---|
| 普通企业 AI PoC | 前 10%–20% | 明显领先 |
| 企业视觉算法研发原型 | 前 20%–30% | 实验纪律较强 |
| 成熟计算机视觉研发团队 | 中位数附近或略低 | 数据与验证能力仍有差距 |
| 顶尖学术视觉研究团队 | 中下水平 | 缺少足够强的研究创新和独立验证 |
| 生产级视觉识别系统 | 不具备可比性 | 尚未完成生产工程验证 |

注意：这里比较的是工程研究纪律，不是模型能力排行榜。

### 2. 工程实现值得肯定的地方

我认为有五项。

**A. 数据管理比较规范**

- SHA 级去重。
- 开发集与 GEN 独立集隔离。
- 门店组级数据管理。
- 正负样本和困难负例分类。
- 合成数据与真实数据用途区分。

这已经超过很多只依赖随机切分的企业视觉项目。

**B. 评估协议比较成熟**

嵌套 LOSO、门店组 Bootstrap、配对差检验，都说明团队已经意识到同一门店的不同图片不能简单视为独立样本。

尤其是以门店组为统计单位，而不是仅仅以图片为单位，这是正确的。

**C. VLM 实验设计有一定独立性**

14 个独立会话、匿名化、真值本机保存、后端 API 取回，以及逐图错误迁移审计。

这些设计能够减少部分提示词迭代过程中的人为干预和选择性报告风险。

**D. 失败实验有完整记录**

不是简单记录某次模型跑分，而是能够指出失败发生在哪里、为什么发生、是否需要关闭某条技术路线。

E7b 的微调路线关闭就是一个很好的例子。

**E. 治理纪律比较清楚**

权利审核未完成、人工金标准缺失、模型生成标注不能直接当真值、结果仍属于 exploratory。

这些限制都被明确写出来了。

### 3. 为什么不是 8.5 分？

因为工程实现还主要停留在研究实验系统。

缺少：

- 可封存的完整模型与推理环境。
- 商业模型版本、参数和服务端行为的完整固定。
- 线上推理性能、成本和吞吐测试。
- 生产阈值与拒识率控制。
- 数据更新后的持续评估机制。
- 真实业务反馈闭环。

我特别指出一个问题：

**322 折 LOSO 不等于 322 个独立的泛化场景。**

如果同一批数据、同一采集环境和相似门店结构被反复分组测试，它能够证明的是一定程度上的门店组泛化，而不是跨城市、跨设备、跨时间的真正外部泛化。

另外，thr_std=0 需要在论文中解释清楚：阈值是每折独立估计、预先冻结，还是由其他统一规则产生。不同情形对应不同的统计解释。

工程方面还有一个容易被忽略的问题：

双通道标注一致率从 95.8% 降到 GEN 集的 80.3%，这说明标注质量并不稳定。44 个分歧样本中，双方错标率都接近一半。

这意味着当前系统不仅存在模型不确定性，还存在真值不确定性。

# 四、实用价值：4.0/10

<badge color="warning">当前不建议进入自动化生产</badge>

这里我会比较严格。

项目已经证明了：

- 可以建立针对特定品牌的视觉识别管线。
- 可以利用多模态模型做复杂语义裁决。
- 可以在特定数据集上达到较好的 F1。
- 可以识别并分析部分系统性误报、漏报。

但它尚未证明：

**在真实业务数据分布下，系统能够以可接受的误报率、漏报率和运营成本稳定运行。**

### 1. 最大的现实问题：评测集与真实业务分布不一致

330 评测集：

- 30 个正例。
- 300 个负例。
- 正例率约 9.1%。

GEN 集：

- 正例率约 49%。

两者不是同一个业务分布。

尤其是 GEN 集没有 render_stock 负例。

因此，GEN 集上 F1=0.917 不能直接解释为实际门店识别准确率。

这里还有一个更重要的问题：

假设系统未来用于全国门店排查，真实目标品牌门店在待识别图片中的比例可能只有 1% 或更低。

此时，即使模型维持不错的召回率，也可能产生大量误报。

在这种业务场景中，F1 不是最重要的指标。

我更关心：

- Precision@实际业务先验。
- 每识别出一家真实门店需要人工复核多少张图片。
- 每千张图片产生多少个错误 MATCH。
- 真实门店的漏检率。
- UNKNOWN 占比。
- 人工复核后的最终正确率。

### 2. 当前最适合的商业应用形态

我认为可以考虑的不是自动确认，而是：

# 五、最大弱点 TOP 3

这是整个评审最重要的部分。

我按照对最终结论的危害排序。

## TOP 1：真值体系不够强，导致整个证据链存在上限

<badge color="danger">最高风险</badge>

当前的双通道标注不是独立的人类金标准。

GEN 集一致率只有 80.3%，44 个分歧样本中，双方错标率约为 50%。

更严重的是：

- 真实门店变体存在边界模糊。
- 副食店措辞、合牌、异色底容易产生分歧。
- Mode B 的 10 个 FN 中，有 7 个来自这些变体。

这意味着当前存在一个根本问题：

**你们还没有建立一套足够稳定、可以独立裁决的品牌身份定义。**

如果连专家对什么是真正的目标品牌门店都无法形成一致意见，那么模型 F1 再高，也无法说明它真正学会了业务定义。

这不是模型优化可以解决的问题。

必须建立人工金标准。

我的建议：

- 至少两名独立人工标注员。
- 一名独立专家仲裁员。
- 盲标，不看模型结果。
- 明确真实门店变体的纳入边界。
- 报告 Cohen's Kappa 或 Krippendorff's Alpha。
- 将难以形成共识的样本单独定义为边界类。

不能只用总体一致率代替标注可靠性。

## TOP 2：GEN 不是足够强的外部泛化验证

<badge color="danger">高风险</badge>

GEN 虽然独立于开发集，但仍来自同期 crawl。

因此，它排除了部分数据泄漏风险，却没有充分排除采集域相关性。

最值得注意的是：

- 开发集 B 模式比 A 模式高 0.02。
- GEN 集 B 模式反而比 A 模式低 0.008。
- 两个数据集的差异均不显著。
- GEN 没有 render_stock 负例。

这说明两个问题。

第一，模式排序不稳定。

第二，数据集对真实业务困难场景的覆盖仍不充分。

我认为这是目前最需要补强的实验。

你们真正需要的不是再采集 200 张类似照片。

而是：

- 新城市。
- 新采集时间。
- 新采集设备。
- 不同地图与街景来源。
- 不同图像质量。
- 真实素材图和商业渲染图。
- 复杂品牌变体。
- 高相似竞品门头。

尤其是 render_stock。

它是整个项目已经明确暴露、却尚未解决的核心域间隙。

## TOP 3：VLM 的优势没有被统计证据充分证明

<badge color="warning">中高风险</badge>

开发集：

- VLM alone F1=0.949。
- Mode A F1=0.931。
- Mode B F1=0.951。

GEN：

- VLM alone F1=0.885。
- Mode A F1=0.917。
- Mode B F1=0.909。

如果只看开发集，容易得出 VLM 架构有效的结论。

但 GEN 告诉我们：

- VLM alone 不再领先视觉基线。
- A、B 模式的差异跨集翻转。
- 配对置信区间全部跨零。

因此，当前还不能证明：

1. 四态证据裁决稳定提升识别性能。
2. A/B 回退机制优于简单基线。
3. VLM 对复杂场景的理解能力能够转化成稳定的业务收益。

更重要的是，VLM 使用 512px 缩略图网格。

对于门头这种高度依赖文字细节、品牌符号、招牌结构的任务，信息损失可能直接限制性能。

目前还没有完成 ROI 两级输入实验。

所以我认为当前架构设计方向合理，但证据链尚未证明其最优性。

# 六、到下一水平，具体还缺什么？

我把下一水平定义为：

**从一个研究型识别原型，提升为一个具有可发表证据、可以受控进入真实业务的视觉身份验证系统。**

建议分四个阶段。

## 阶段一：建立真正的金标准

<badge color="danger">P0：必须优先</badge>

目标不是扩充图片数量，而是提高真值质量。

建议：

| 工作 | 具体要求 |
|---|---|
| 人工盲标 | 两名独立标注员 |
| 专家仲裁 | 一名独立专家 |
| 标注协议 | 固定品牌身份与真实经营场景规则 |
| 边界样本 | 单独建立变体门店类别 |
| 一致性统计 | Kappa / Alpha + 混淆矩阵 |
| 数据冻结 | 建立人工金标准版本及 SHA |

建议先做 300–500 张人工盲标专项集。

其中应重点增加：

- 真店变体。
- 竞品。
- 同名异业。
- 设计图。
- 渲染素材。
- 真实门头低质量图。

这里的数量是建议的首轮工程规模，不代表已经达到统计功效要求。

**验收条件：能够证明标签定义稳定，且边界样本有明确处理规则。**

## 阶段二：真正的外部泛化验证

<badge color="danger">P0：必须优先</badge>

建议构建三套独立测试集。

<box border radius="lg" gap={2} padding={3}>
  **A：跨城市泛化集**
  <text color="secondary" size="sm">新城市、新门店、新街区，验证空间迁移。</text>
  <divider color="subtle"/>
  **B：跨采集源泛化集**
  <text color="secondary" size="sm">不同地图、街景、拍摄设备和图像处理流程，验证采集域迁移。</text>
  <divider color="subtle"/>
  **C：困难负例专项集**
  <text color="secondary" size="sm">render_stock、同名异业、竞品、设计图和合成素材，验证误收风险。</text>
</box>

我的建议是：

不要将这三套数据简单混合成一个总 F1。

必须分别报告结果。

尤其需要对 render_stock 建立独立的召回和误收指标。

否则整个项目最大的已知技术缺陷仍然存在。

## 阶段三：重新验证架构，而不是继续堆模型

建议做一组严格的消融实验。

| 对照组 | 验证问题 |
|---|---|
| E8-G | 纯视觉基线 |
| VLM alone | 单独语义裁决的能力 |
| E8-G + VLM | 分层架构的实际增益 |
| E8-G + VLM + ROI | 细粒度输入的价值 |
| E8-G + 规则 | 简单规则能否替代部分 VLM |
| 四态裁决 + 校准阈值 | UNKNOWN 是否真正降低错误 MATCH |

我特别建议增加两个实验。

**实验一：ROI 两级输入。**

先用整图判断场景，再对门头区域进行高分辨率分析。

不要把 512px 缩略图网格当作最终架构。

**实验二：选择性预测。**

允许系统拒绝自动判断。

研究：

- 自动接受比例。
- 自动接受样本的错误率。
- UNKNOWN 比例。
- 不同人工复核工作量下的风险变化。

这比单纯追求 F1 更接近真实业务价值。

## 阶段四：真实业务验证

建议建立一个小规模影子运行。

例如：

- 选择一个新城市。
- 使用真实业务采集图片。
- 不让模型自动改变业务数据。
- 人工独立复核全部预测。
- 统计每千张图片的错误 MATCH。
- 统计漏检和 UNKNOWN。
- 记录人工复核时间与成本。

建议至少进行一个完整采集周期，并保留时间外测试集。

最终形成：

**模型效果 → 业务准确性 → 人工成本 → 单位识别成本。**

到这里才真正具备商业化评价的基础。

### 为什么工作坊是当前合理上限？

1. 真实品牌门头识别中，品牌身份和真实经营场景需要联合验证。
2. 在开发集上有效的 VLM 裁决策略，不一定在独立采集数据上保持相同排序。
3. 领域分布差异、合成素材和伪相关特征可能比模型容量更重要。

其中第三项尤其值得深入。

- 明确的新方法或理论贡献。
- 多品牌、多城市验证。
- 足够可靠的人工金标准。
- 有说服力的跨域对照实验。
- 统计功效和真实业务先验下的性能分析。

# 八、我认为最值得重新认识的三个研究发现

这部分不是重复项目总结，而是我对项目价值的重新排序。

### 发现一：模型微调可能让系统更差

E7b 是一个非常重要的结果。

它说明在小样本、域覆盖不完整的情况下，增加模型训练自由度可能加剧伪相关学习。

这个发现比某次 F1 提升 2 个百分点更值得保留。

它值得进一步发展为一条研究假设：

> 对于具有强烈采集域偏差的品牌视觉识别任务，冻结预训练表征加受约束的证据裁决，可能比直接微调视觉编码器更稳健。

注意，目前它仍然是假设，不是已经证明的普遍规律。

### 发现二：UNKNOWN 应当是系统能力，而不是模型失败

传统识别系统往往把无法判断理解为失败。

但在真实品牌身份识别中：

- 品牌变体可能是真店。
- 设计图可能包含真实品牌文字。
- 同名异业可能存在相似标识。
- 低质量照片可能丢失决定性信息。

此时，强制二分类会制造虚假的确定性。

UNKNOWN 如果能够有效隔离高风险样本，就可能成为系统可靠性的重要组成部分。

但必须通过选择性预测实验来证明，而不是只在分类标签中增加一个类别。

### 发现三：真正的瓶颈可能是业务知识边界，而非视觉模型能力

我认为这个发现目前被低估了。

例如，副食店措辞、合牌、异色底等情况。

它们未必是图像识别问题。

而是一个更基础的问题：

**什么样的真实经营场景，才算这个品牌的门店？**

这是品牌治理、加盟管理、渠道管理和视觉识别之间的交叉问题。

如果不解决这一层，单纯升级视觉模型很可能收益有限。

## 十、最后一个更尖锐的判断

我认为这个项目目前处于一个容易被误判的阶段。

因为它已经有：

- 比较漂亮的 F1。
- 比较完整的技术架构。
- 多轮实验结果。
- 大量数据资产。
- 相当成熟的工程记录。

这些东西容易让人产生一种感觉：项目已经接近成功。

但从独立评审角度看，**项目最重要的科学问题其实还没有解决：它究竟识别了品牌身份，还是识别了特定数据采集环境下与品牌身份相关的视觉模式？**

E7b 的失败、GEN 的模式排序翻转、render_stock 域间隙和真值分歧，都指向这个问题。

如果下一轮实验能够证明：

1. 在独立城市和独立采集条件下，仍然保持稳定的识别能力；
2. 人工专家对品牌身份的定义具有可接受的一致性；
3. 四态机制确实能够降低错误 MATCH，而不是仅仅改变分类结果；
4. VLM 分层架构在相同人工复核成本下，优于纯视觉基线；

那么这个项目就会发生一次实质性的水平跃迁。

届时我会考虑把研究价值从 6.2 提升到 7.5 左右，并重新评估会议论文的可能性。

**当前我的最终判断：这是一个工程质量不错、研究方向正确、负结果价值较高，但尚未完成关键外部验证的应用研究项目。最大的风险不是模型不够先进，而是把有限数据上的识别成绩误认为已经掌握了可迁移的品牌身份识别能力。**

这就是我认为最应该坚持的下一阶段研究纪律。
