# S0 目录外拒识升级评审裁决

<row align="center" gap={2}>
  <badge color="success" size="lg">总体：APPROVE WITH CONDITIONS</badge>
  <text color="secondary" size="xs">建议批准 S0，附带明确的后续整改门槛</text>

**核心判断：S0 的方向正确，已经显著改善演示诚实性，但尚未解决真正的开集视觉识别问题。** 当前最大的风险不是 FOREIGN 别名表，而是系统仍然允许高置信度视觉分类器把完全不认识的品牌判成目录内品牌。

## A. FOREIGN 别名表 + 独立行门控

<badge color="success">CLOSED</badge>

**裁决：当前设计可以成立，但 CLOSED 仅代表 S0 规则设计通过，不代表 FOREIGN 机制已经具备生产级可靠性。**

认可三个设计决定：

1. 目录别名优先于 FOREIGN：正确。目录门店即使出现竞品广告，也不应直接被拒识。
2. 短别名独立整行匹配：正确。比简单子串匹配更能控制误触发。
3. 删除 TODAY、康师傅、统一：正确。体现了对品牌语义和门头识别对象边界的理解。

但仍有五类系统性风险：

| 风险 | 具体问题 | 建议 |
|---|---|---|
| OCR 同框污染 | 货架、海报、隔壁招牌可能进入 OCR | 增加招牌区域约束 |
| 多品牌同框 | 最长匹配不代表主门店品牌 | 引入空间位置和主视觉优先级 |
| 别名碰撞 | 短英文、缩写可能具有多重语义 | 建立别名冲突测试集 |
| FOREIGN 漏表 | 未收录的目录外品牌仍会进入视觉回退 | FOREIGN 不应承担完整开集拒识责任 |
| OCR 错读 | 错误字符可能形成其他品牌别名 | 记录 OCR 原文、匹配片段和置信度 |

**特别指出：独立行门控不是语义消歧。**

它解决的是子串误触发，不解决 OCR 错误、同框品牌竞争、空间归属和别名歧义。

建议增加一项长期测试：目录内门店 + 目录外品牌广告 + 货架品牌 + 相邻门店四种组合的交叉测试。

目前不必因此阻止 S0。

## B. 88 张纯视觉错进目录：S1/S2/S3 优先级

<badge color="warning">PARTIAL</badge>

**裁决：问题定位正确，但升级路线需要调整优先级。**

我的建议：

<box border radius="lg" gap={3} padding={3}>
  <row align="center" justify="between">
    **第一优先：S1**
    <badge color="success">先做</badge>
  </row>
  CLIP 零样本 OOD / 负向提示评分。

  原因：不需要立即改变现有 42 个探针的训练体系，可以先验证现有视觉特征是否具有区分已知与未知品牌的能力。

  <divider color="subtle"/>
  <row align="center" justify="between">
    **第二优先：S2**
    <badge color="info">随后做</badge>
  </row>
  显式负类训练（Outlier Exposure）。

  原因：88 张纯视觉错误样本说明系统缺乏真正的 NOT-IN-CATALOG 学习能力。S2 更直接地针对这一缺陷。

  <divider color="subtle"/>
  <row align="center" justify="between">
    **第三优先：S3**
    <badge color="secondary">兜底层</badge>
  </row>
  本地小 VLM 四态裁决。

  原因：VLM 有机会弥补细粒度开集识别的不足，但不能把它当成自动正确的裁判。
</box>

这里我想特别挑战一个技术假设：

**S1 不一定比 S2 更有效，S2 也不一定能解决真正的细粒度开集问题。**

原因是：

- CLIP 的 OOD 分数可能只是衡量图像与文本提示的匹配程度，不等于目录外品牌识别能力。
- 88 张负例可能覆盖的品牌和视觉形态有限。
- Outlier Exposure 容易学习到这批负例的特征，而不是学习到一般性的未知品牌边界。
- 如果目录外品牌与目录内品牌视觉高度相似，单纯负类训练仍可能失效。

### 我建议增加一个关键验证门槛

不要只比较总体准确率，而要同时比较：

| 评估指标 | 目的 |
|---|---|
| OOD AUROC | 已知与未知的区分能力 |
| FPR@95TPR | 保留已知品牌识别能力时的误接纳率 |
| Unknown Recall | 目录外品牌拒识能力 |
| Known Brand Accuracy | 目录品牌准确率损失 |
| 新品牌留出测试 | 检查是否真正泛化 |

尤其是最后一项。

必须按品牌划分训练、校准和测试，而不是简单随机拆分照片。

例如：瑞幸进入测试集时，不能让瑞幸的其他照片已经出现在负类训练集。

**对 S3 的额外要求：**

VLM 输出必须保留 UNKNOWN 和 OUT_OF_SCOPE，不得强制从 42 个目录品牌中选择一个。

E10 的 F1=0.951 是有价值的依据，但不能直接推导本地 Qwen2.5-VL 也能达到同样表现。

## C. 3.6% 拉丁误拒是否可以接受？

<badge color="warning">PARTIAL</badge>

**裁决：S0 阶段可以暂时接受，不能作为长期规则接受。**

这里有一个非常重要的区别：

- 如果目标是减少目录外品牌误报，牺牲少量目录品牌召回可以理解。
- 如果目标是建立可靠的品牌识别系统，那么系统不应仅凭文字字符类型就否定视觉判断。

3.6% 意味着目录品牌测试样本中有 9/250 被新规则误拒。

这不是可以忽略的损失。

更重要的是，拉丁字母不是未知品牌的可靠代理变量。

例如：

- 目录内品牌可能采用英文标准字。
- 目录外品牌可能只有中文招牌。
- 中英文混排招牌很常见。
- OCR 可能把装饰性字母误识别为连续英文字符。

### 建议

保留 S0 规则作为暂时的安全保护，但将它降级为弱证据，而不是最终拒识条件。

未来应该由 S1/S2 结合视觉分数、OCR 证据共同决定。

建议设置双门槛：

1. 目录品牌识别准确率不得出现超过预设非劣界限的下降。
2. 目录外错误进入目录的比例必须显著下降。

**不能为了提高拒识率而无限牺牲目录品牌召回率。**

另外，9/250 的估计仍有抽样不确定性，不能直接把 3.6% 当作真实业务误拒率。

## D. 诚实税：79.6% 与 E25 的 95% 分开汇报是否足够诚实？

<badge color="warning">PARTIAL</badge>

**裁决：分开汇报是正确的，但目前的报告方式还不够完整。**

我认可明确区分：

- Demo 决策层：79.6%。
- E25 评分协议：95%。

二者评估协议不同，不能直接比较。

尤其是 Demo 增加了拒识逻辑，不能只用传统分类准确率解释。

但我认为还缺少一个重要问题：

**79.6% 到底是怎样计算出来的？**

必须明确区分：

| 指标 | 必须回答的问题 |
|---|---|
| Known Accuracy | 目录内样本中正确识别比例 |
| Known Coverage | 目录内样本中实际给出目录品牌答案的比例 |
| Known Rejection | 目录内样本被拒识的比例 |
| Unknown Rejection | 目录外样本被正确拒识的比例 |
| Unknown False Acceptance | 目录外样本被错判成目录品牌的比例 |
| Wrong FOREIGN | 目录外样本被报成另一个错误的目录外品牌比例 |

还需要一个统一的混淆矩阵。

目前的 79.6% 是混合 train+test 口径，不能作为独立测试集上的泛化准确率。

### 我认为真正诚实的报告方式

每个版本必须同时公布两张成绩单：

**第一张：识别能力成绩单**

传统 E25 评分协议，保证跨版本可比。

**第二张：决策诚实性成绩单**

增加拒识率、误接纳率、覆盖率、错误品牌回答率。

再额外披露目录品牌的 3.6% 误拒成本。

这样才不会出现一种情况：系统通过大量输出 UNKNOWN 获得漂亮的拒识指标，却损失了实际识别价值。

因此，当前分开汇报方向正确，但还需要建立完整的 selective prediction 评价体系。

## E. 权利边界

<badge color="success">CLOSED WITH RESTRICTIONS</badge>

**裁决：当前边界可以接受，但必须严格限制用途。**

我认可：

- 高德采集照片权利状态为 pending_review。
- 当前仅内部评测。
- 不将照片直接转为训练数据。
- 不部署到生产系统。
- 不把 VLM 裁决直接视为训练标签。

但要明确几个容易混淆的边界：

| 使用行为 | 当前判断 |
|---|---|
| 内部受限评测 | 可以在授权和适用条款允许的范围内进行 |
| 内部报告统计 | 可以，但应保留来源与使用记录 |
| 公开展示原始照片 | 暂不允许 |
| 对外提供照片数据集 | 不允许 |
| 用照片训练模型 | 权利审核通过前不允许 |
| 生产部署使用 | 权利审核通过前不允许 |
| 将 VLM 裁决作为训练真值 | 不允许 |

特别强调：

**图片能够被采集，不代表可以被任意使用；能够用于内部评测，也不代表取得模型训练或商业展示授权。**

此外，SHA256 和 dHash 去重只是数据治理措施，不是版权许可证明。

建议建立逐图权利台账，至少记录来源、采集时间、使用范围、授权状态、删除要求和审核责任人。

### 批准附带的五项条件

1. **FOREIGN：** 补充同框品牌、OCR 污染和别名碰撞测试，不扩大短别名的模糊匹配范围。
2. **S1/S2：** 先做 S1，随后做 S2，对照实验必须包含未见过的目录外品牌。
3. **3.6%：** 暂时接受，不得将拉丁规则固化为长期最终拒识机制。
4. **评价体系：** 同时发布 E25 可比指标和 Demo 决策指标，明确覆盖率与拒识代价。
5. **权利治理：** pending_review 数据不得越权进入训练、公开展示或生产部署。

### 我认为最重要的战略判断

这轮升级实际上暴露了一个架构层面的转折点：

**S0 之前，系统是在回答「这像哪个品牌」；S0 之后，系统开始尝试回答「这是不是我认识的品牌」。**

这两个问题并不等价。

前者是封闭集识别，后者是开放集识别。

未来系统的核心能力不应该是不断扩充 FOREIGN 品牌别名表，而应该是建立一个真正有能力表达：

- 我认识这个品牌；
- 我认识它，但它不属于目录；
- 我无法确定；
- 这根本不是有效门头识别对象。

的四态决策体系。

我建议把 **S1+S2 的开集能力验证**作为下一阶段的核心任务，把 S3 定位为独立裁决与疑难样本兜底层。

在这项能力通过独立品牌留出测试之前，不应宣称系统已经具备可靠的目录外拒识能力。
