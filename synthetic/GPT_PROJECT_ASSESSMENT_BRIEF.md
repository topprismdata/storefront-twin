# 项目评审请求:左邻右舍门头识别——全项目技术简报

请以独立第三方视角,客观评价本项目的**价值**与**实现水平**。要求校准化评分(1-10,附理由),不做客套。简报含全部失败与死路,未粉饰。

## 1. 任务

为连锁便利店品牌"左邻·右舍"(红底白字+⊙圆环红蓝VI)构建:真实照片+难负例数据集、识别管线、以及证据化身份验证层。最终形态=视觉基线(召回)+VLM 四态证据裁决(精度)的分层架构。

## 3. 管线架构

特征层: CLIP+DINOv2+SigLIP 四视图嵌入(full/crop) → E8-G 冻结融合基线 s=0.4·s_clip+0.4·s_dino_mc+0.2·s_probe(thr 0.636,探针仅用合成数据训练) → E10 VLM 证据层: 四态裁决(MATCH/NON_MATCH/UNKNOWN/OUT_OF_SCOPE),UNKNOWN 回退基线(A模式不救/B模式救援)。

## 5. 失败与死路(如实)

1. **E6-v1 弱标签探针 F1 0.629**:域缺口(池内无render_stock负例),v2修到0.817
2. **E7 金标签训练**:gold_only F1 0.169(27负例撑不起判别);混合0.812<基线0.848
3. **E7b DINOv2末块微调**:val F1 0.93 但 330 冻结阈值 F1 0.504(59FP中36个render_stock;eval域最优可达仅0.727)——微调把"带品牌字门头照=正例"学死,合成素材图恰好形似。结论:瓶颈=render_stock域表征,非标签非容量;训练路线关闭
4. **OCR 门禁失败**:29/30 正例 tesseract 读不出(门头字体艺术化),OCR 不能当硬门禁
5. **AnyLoc 检索**:初期 R@1 90% 系 bool bug,修正后 43% 与基线持平,已撤回
6. **v2 强化指令**:定向回归 13/13 通过但全量零净收益+2个新翻转——定向验证不能预测全量回归
7. **双通道标注**:一致率仅80.3%,分歧集内双方错标率约50%(26/44 vs 21/44)——任何单通道VLM标注都不可直接当真值
8. **变体门店边界**:真店变体(副食店措辞/合牌/异色底)是标注仲裁和VLM裁决共同拉锯的模糊带;ModeB 10个FN中7个为此类

## 6. 方法学资产

- 嵌套LOSO(322折)+门店组整簇Bootstrap(2000次,seed固定,percentile CI)+配对差检验
- VLM盲测:14独立会话/匿名化/真值本机/后端API取回;迁移矩阵逐图审计
- sha级数据隔离与去重;双通道跨模型标注+全分辨率仲裁;错误分型审计(竞品误MATCH/素材误MATCH/真店误拒/回退继承 分开计量)
- 治理:真实图 rights=pending_review,G0/G1 未过,全部结果标注 exploratory,VLM裁决不自动作训练标签(用户例外授权的一次金标注除外,且如实标注"跨模型VLM标注,非人工双盲")

## 7. 已知局限

- 正例门店组仅24(330)/gen集正例率49%偏离真实先验;单一品牌、中国县域场景为主
- VLM裁决依赖商业闭源模型(版本未封存);输入为512px缩略图网格(已知信息损失,ROI两级输入未实施)
- 独立泛化集仍来自同期采集(crawl批次),非真正新城市/新设备采集
- render_stock 域间隙未解决(基线在含素材图的场景会退化);部署级阈值标定未做
- 权利审核(G0/G1)、人工双盲金标准、专家复核均未通过——不可部署
