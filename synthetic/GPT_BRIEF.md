# 左邻右舍门头识别：研究状态简报（供 GPT 讨论）

日期 2026-11-12。所有数字为本机实测（measured），视觉判断经 vision 核验。请基于证据给第二意见，不要泛泛而谈。

## 0. 任务与治理约束（不可违反）
- 任务：判断一张门头照片是否属于"左邻右舍"连锁便利店品牌（L0 品牌二分类），以及属于哪个 VI 风格簇（L1 细粒度检索，CS-01~06）。
- 品牌 VI：红 #e60012 / 蓝 #005dac，⊙ 圆环标志，标准字"左邻·右舍"，副标 PLUS / Good Neighbors。有官方 SI 手册（简约/标准/都市三版）。
- **权利约束**：所有真实图 rights=pending_review，G0/G1 权利门未过 → 一切实验是探索性 probe，不能部署、不能对外声称准确率。真实图只能做 kNN 参考/评估，不能做监督训练（除非权利审核后）。
- **合成数据**：Blender 参数化 3D 孪生渲染 820 张（self_created，synthetic_train_only），含 300 张竞品难负例。绝不把真实照片当背景/纹理。
- 评估隔离：kNN 参考与 query 按 store_id 做 LOSO（留店隔离），防同店泄漏。

## 1. 当前最佳 L0（E8-G 三通道融合）
分数 s = 0.4·s_clip + 0.4·s_dino_mc + 0.2·s_probe，阈值 0.636（严格 >）。
- s_clip = CLIP 全图 kNN 正例投票比例（品牌语义）
- s_dino_mc = DINOv2 多裁剪 kNN，再 clip((x-0.3)/0.5)（局部结构，多裁剪救检测失败）
- s_probe = 合成 820 张训练的 logistic 探针 predict_proba（合成先验）

**工作点（30 正例 / 300 负例，LOSO）**：TP 28 / FP 7 / FN 2 → **P 0.800 / R 0.933 / F1 0.862**
**开集协议（arXiv:2403.16528）**：AuPR **0.925**，P@95R **0.707**，R@95P **0.600**
单通道 AuPR：clip 0.659 / dino_mc 0.766 / probe 0.324。

- img_0308 render_stock：**vision 判为实拍，招牌"邻儿"绿白配色（竞品）**，标签疑似误标。clip 0.8 / dino 1.0 / probe 0.06。
- img_0494 same_name_unrelated：实拍，竖式白底黑字"左邻右舍"但挂在旧楼外立面，非超市门头（同名餐馆/社区）。clip 1.0 / dino 0.219 / probe 0.838。

**关键观察**：
1. 7 个 FP 里 6 个 s_clip≥0.8 —— CLIP 把"红底便利店招牌"一律当本品牌，是颜色/品类捷径，不读具体品牌字。
2. 4 个 render_stock 实为**实拍竞品**（美宜佳/芙蓉兴盛/邻儿/凯烨），标签噪声。真正 FP 根因是**竞品混淆**，不是"渲染 vs 实拍"。
3. 合成探针对 5/6 竞品 FP 给 ≤0.06 低分（正确拒绝），但 0.2 权重压不过 clip+dino。
4. img_0494 同名异业：唯一看穿的是 DINOv2（0.219），CLIP/probe 都被"左邻右舍"四个字骗了（=1.0/0.838）。

## 3. 已试过的修复（实测，均不理想）
- **探针否决规则**（s_probe<τ 强制拒绝）：τ=0.02 → P0.815/R0.733/F1 0.772；τ=0.2 → P0.944/R0.567。**召回崩**，因为域差使真实正例 probe 也低，否决误伤正例。失败。
- **权重网格**（wc/wd/wp 多组合）：0.4/0.4/0.2 仍最优 F1 0.862；提高 probe 权重到 0.3 → R1.0 但 P 跌到 0.698。无免费午餐。
- **E9 AnyLoc 聚合**（中间层 value+VLAD，arXiv:2308.00688）：L1 R@1 仅 43%（与 CLS 持平），R@5 76.7→83.3% 边际改善。初版报 90% 是布尔 bug 伪影已撤回。VPR 实例级匹配增益不迁移到类别级门头细粒度。
- **朴素合成训练**：sim-to-real 域差，易负例→"红板=品牌"捷径（P12%）；难负例修特异性但压召回。合成只能当融合先验，不能直接训分类器。

## 4. 文献对照（已读原文）
- arXiv:2403.16528：CLIP 开集 P@95R≈46% 是 VLM 已知缺陷；我方融合 P@95R 0.707 已显著优于裸 CLIP。应报 AuPR/P@95R/R@95P。
- arXiv:2405.03243：合成域差集中末层，少量真实数据微调末层可恢复 → E6 真实监督是正解，但卡在权利审核。
- arXiv:2509.25811（Logo-VGR）：VLM 比较式识别（query vs 候选 logo 参考 + "以上都不是"），学推理过程比学答案泛化好，OOD +10pp → 拟用于打竞品/同名异业 FP。
- arXiv:2308.00688（AnyLoc）：已实测，增益不迁移（见上）。
