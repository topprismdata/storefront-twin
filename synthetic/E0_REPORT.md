# E0 基线报告（B0a：色带/Logo 模板 + OCR 规则）

实现 2026-11-11。设计文档 §7.1 B0a / §9.1 E0：**无深度适配，纯规则能达到什么效果？**
基线：`synthetic/e0_baseline.py`（BASELINE_VERSION=`e0-b0a-rule-v1.0`）。

## 1. 方法

| 阶段 | 实现 |
|---|---|
| 招牌检测 | HSV 红/蓝掩膜（官方 VI 色域，先验固定）→ **行/列投影**定位招牌带（对碎片化红板鲁棒，不依赖连通域） |
| 四点校正 | 候选框裁剪 + 放大（保留长宽比） |
| OCR | tesseract `chi_tra`+`chi_sim` 双模取品牌字命中最优；白字红底→低饱和高亮度掩膜提取亮字 |
| L0 品牌鉴别 | 中文字「左邻右舍」命中 + 英文 GoodNeighbor + 编号 No.XXXX 制式组合 |
| L1 候选簇规则 | PLUS→CS-05 / 超市→CS-06 / 蓝底→CS-04 / 编号→CS-01 / 红蓝常规→CS-03 |
| 选择性预测 | not_brand / unknown_style / ambiguous_or_hybrid 拒识（§7.4） |

阈值先验固定，**不据测试集调参**。

## 2. 结果

### 合成集（55 张，构造标签，验证规则自身）

| 指标 | 值 |
|---|---|
| L1 候选簇准确率 | **18.5%**（10/54 graded） |
| L0 品牌召回 | **24.5%**（13/53） |
| L1 簇分类（品牌已检出条件下） | **69.2%**（9/13） |
| CF-4 异常拒识 | 1/1 ✓ |

每簇：CS-01 0% / CS-02 0% / CS-03 25% / CS-04 37.5% / CS-05 11% / CS-06 25%。

### 真实集（30 正例 + 38 分层负例，**探索性探针**）

| 指标 | 值 |
|---|---|
| L0 品牌召回 | **6.7%**（2/30） |
| L0 品牌特异度 | **100%**（0/38 误报） |
| 无招牌候选的正例 | 12/30 |

> **治理声明**：真实图权利全部 `pending_review`，G0/G1 门禁未过。本评估为**可行性探针**，非正式精度宣称；不发布 Macro-F1 高置信结论（§9.2）。

## 3. 核心发现

1. **瓶颈是 OCR，不是规则**：tesseract 对招牌艺术黑体「左邻右舍」本质弱——读成"左低右全/太聞冇舍/癌衣明"等乱码。一旦品牌字读出，L1 簇规则达 69.2%，证明**规则分类逻辑有效，OCR 前端是短板**。
2. **检测在真实照片上退化**：12/30 正例连招牌候选都检不出（小招牌/大角度/复杂光照/非标准色）。合成集检测较好（投影法），真实集域差显著。
3. **高特异度低召回**：规则保守，0 误报但漏检绝大多数。适合作**高精度冗余通道**（§7.1 "若 B0a 达标保留为部署主干或联合冗余"），但单独不足以支撑识别。
4. **英文副标信号有限**：GoodNeighbor 在白字掩膜下同样难读出，未能显著提升召回。
5. **sim-to-real 域差实证**：合成集品牌召回 24.5% vs 真实 6.7%——合成边缘干净/字体规整，真实照片退化严重。印证 §8.3 "域差"风险，M0 合成不能替代真实验证。

## 4. 对后续实验的指引（含文献复核 2026-11-11）

**架构纠偏（文献查证后）**：本 E0 把 OCR 当主识别器是**架构错位**。我们的任务是"已知品牌 + 细粒度版型识别"，属品牌/logo 视觉检索，**不是**"读任意店名"的店招 OCR 任务。两类任务文献分野清晰：

- **店招文字读取**（地图/智慧城市）才以 OCR 为核心：街景店招竞赛冠军方案（arXiv:2501.02811）用 检测→文字检测→识别→阅读顺序 四阶段重型 OCR 流水线，14 队冠军 F-score 仅 0.6672——OCR 路线又难又脆。
- **品牌/logo 识别**（我们的任务）以纯视觉为主：LogoDet-3K（arXiv:2008.05359，3000 类 logo / 20 万目标）是纯视觉检测基准，无 OCR；DINOv2 被推荐为细粒度实例检索首选，CLIP 用于开放词表/文本对齐。

**我们的 6 候选簇是结构差异（PLUS 角标/立体发光字/彩钢条/编号牌/字体风格），不是文字差异**——DINOv2/SigLIP 局部 patch 特征 + FAISS 检索（设计文档 B2/B3/E1/E3）才是主力，而非 OCR。

- **E0 重新定位**：不是主基线，而是验证了"OCR 冗余通道"——高特异度(100%)低召回，适合品牌确认的保守校验，不能单独部署（§7.1）。
- **主力基线应是 E1/E3**：DINOv2/SigLIP 视觉嵌入 + FAISS 检索，优先投入。
- **OCR 降级为可选融合分量**（§7.2 s_ocr）：仅在"视觉不可区分的变体消歧"时启用（零售 FGVC 类比：可口可乐原味 vs 零度共享 logo，靠 OCR 读差异字符）。我们 6 簇均有结构差异，OCR 边际价值低；若用则选深度场景 OCR（PaddleOCR）而非 tesseract。
- **检测器需学习化**：投影模板对真实多样招牌不足，E4 的 ROI/检测学习有必要。
- **合成数据价值定位**：M0 合成适合验证规则/流程（构造标签），但 sim-to-real 域差大，训练增益须 E7/E8/E9 在真实域验证。

## 6. 诚实缺口

- 真实集仅 30 正例 / 38 负例探针，样本量不足以支撑统计结论（§9.2 INCONCLUSIVE）。
- OCR 未调优（双模取最优已是合理基线）；未试 PaddleOCR 等深度 OCR。
- 检测阈值先验固定，未针对真实域优化（避免测试集调参）。
- 候选簇 L1 真值本身是视觉模型聚类（candidate_unverified），非金标准。
